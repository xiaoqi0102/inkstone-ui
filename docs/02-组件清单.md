# 02 · 组件清单（API 速查）

标 ⭐ 的是本库重点实现、值得单独讲清实现的件；标 `shadcn` 的是标准件（按令牌重写过）。

---

## 外壳层

### `AppShell` ⭐
整体布局：导航 + 顶栏（Logo / 会滚动切换的页面名 / 右侧动作）+ 内容区。

```tsx
<AppShell
  nav={<DockNav … />}          // 必填
  logo={<Logo />}
  title="请求日志"              // 会做方向感知的切换动画
  previousTitle="首页"          // 用于判断动画方向（往下翻 / 往上翻）
  actions={<Button>新建</Button>}  // 固定在右侧，永不换行
>
  {children}
</AppShell>
```

实现要点：布局用 `grid` 而非 flex —— `md:grid-cols-[auto_1fr] md:grid-rows-[auto_minmax(0,1fr)]`。
`minmax(0,1fr)` 不可省，否则内容区撑破行高、滚不起来。

---

### `DockNav` ⭐（本套 UI 的门面）
悬浮胶囊导航。手机底部居中横排；`md:` 断点起变左侧竖排吸顶。

```tsx
const NAV: DockNavItem[] = [{ id: 'home', label: '首页', icon: Home }, …]
<DockNav items={NAV} value={page} onChange={setPage} onPrefetch={(id) => prefetchPage(id)} />
```

| 参数 | 说明 |
|---|---|
| `items` | `{ id, label, icon: LucideIcon }[]` |
| `value` / `onChange` | 当前选中与切换回调 |
| `onPrefetch` | 悬浮/聚焦/触摸/点击时触发，用于预加载页面代码或数据 |
| `className` / `ariaLabel` | 覆写容器样式 / 无障碍名 |

**两个滑块**：激活滑块（`bg-sidebar-primary`）随当前页过渡；悬浮滑块（`bg-sidebar-accent`）随鼠标。
**关键坑**：首次进导航时，悬浮滑块必须先**在不可见状态下瞬移**到目标位置再淡入 ——
做法是 `flushSync` 同步提交位置 + 读一次 `getBoundingClientRect()` 强制样式落地，然后才打开 opacity。
不这么做，鼠标一进导航就会看到一条横线从上一项扫过来。
**改尺寸必改两个数**：步长移动端 `2.75rem`（`size-10` + `gap-1`）、桌面端 `3.75rem`（`md:size-12` + `md:gap-3`）。

---

### `PageHeader`
内容区顶部条：左标题/描述，右动作。

**硬规则**（踩过：标题一长就把按钮挤到第二行，整行高度跳变）：标题列 `min-w-0` + `truncate` 自己截断；
动作列 `shrink-0` + `whitespace-nowrap` 永不缩不折。同类区块（如日志页①②两组标题+按钮）请用同一套，保证左右边缘对齐。

## 数据展示层

### `StatCard` ⭐
`label` / `value` / `unit` / `icon` / `trend` / `footer` / `glow`。
数值与单位分开渲染（大号数字 + 小号次要色单位），这样 `1234` 和 `12.3` 两种量级的卡片视觉重量一致；数值滚动时单位不动，页面不抖。

### `MetricTabs<T>`
分段切换，选中项背后有滑动底（`layoutId` 共享布局）。
`options: { value, label, badge? }[]`；`value`；`onChange`。

### `VirtualizedList<T>` ⭐
长列表虚拟滚动（`@tanstack/react-virtual`）。只渲染视口内的行，DOM 数恒定。

```tsx
<VirtualizedList
  items={logs}
  estimateSize={44}  gap={4}
  getItemKey={(item) => item.id}
  renderItem={(item, index) => <Row … />}
/>
```

⚠ 容器必须有确定高度（父层 `h-full` 或 `flex-1 min-h-0`），否则拿不到滚动高度、虚拟化退化。

### `VirtualizedGrid<T>` ⭐
卡片墙的虚拟滚动。比 `VirtualizedList` 多两件事：**响应式列数**（列数由容器实际宽度决定，不是窗口宽度）+ **行级虚拟化**（一行放 N 张卡，行高自动测量）。

```tsx
<VirtualizedGrid
  items={channels}
  columns={{ default: 1, sm: 2, lg: 3, '2xl': 4 }}
  estimateItemHeight={84}  gap={12}
  getItemKey={(item) => item.id}
  renderItem={(item) => <ChannelCard … />}
  layout="grid"            // 'list' 强制单列
  onReachEnd={loadMore}    // 触底加载
  reachEndEnabled={hasMore} reachEndOffset={1}
  footer={<div>加载中…</div>}
/>
```

改这个组件前，先看它源码注释里的**三个坑**：① 行 key 必须锚定该行首项（否则从头部插入数据时实测高度缓存全失效、间距抖动）；② `measureElement` 用 `offsetHeight` 而不是 `getBoundingClientRect().height`（避开进场 scale 动画的干扰）；③ 触底加载要一次性 ref 守卫（否则连环触发）。这三点都是早期实现里踩过、并记在代码注释里的，别手滑删掉。

### `Sparkline`
迷你趋势图，给统计卡角落用。无坐标轴 / 无 tooltip / 无网格 —— 40px 高的位置塞这些只会变成噪音，它只负责传达"形状"。
`data` / `dataKey` / `height` / `color`（默认 `var(--primary)`，自动跟随主题）。

### `JsonViewer`
自研可折叠 JSON 树，**零第三方依赖**（不引入任何 JSON-view 库）。
按类型着色（key 蓝 / string 绿 / number 琥珀 / boolean 紫 / null 灰）、折叠时显示 `…N 项…`、顶部一键复制原始 JSON 串。
`value` / `name`（头部标题）/ `defaultExpandDepth`（默认展开层数）/ `maxHeight`（超出内部滚动）。

### `RequestDetail` / `CodeBlock` ⭐
把一次调用**完整还原**出来，用于排障。

```tsx
<RequestDetail
  fields={[{ label: '模型', value: 'gpt-5.1', mono: true }, …]}
  request={{ method: 'POST', url, headers, body }}   // 自动渲染 请求体 + curl
  response={responseText}
/>
```

三条设计规矩（都是排障时逼出来的）：
1. 提示词/请求体**多行原样展示**（`whitespace-pre-wrap break-all`），绝不压成一行 —— 一行等于没法看。
2. 每个块右上角独立复制按钮：**curl 与 body 分开**（有时只要 curl，有时要把 prompt 单独拿去改）。
3. 超过 14 行的块折叠（`max-h` + 滚动），避免超长 prompt 把页面撑爆。

`buildCurl(request)` 也能单独用，把 method/url/headers/body 拼成可直接粘进终端的命令。

### `SortableList<T>` ⭐
拖拽排序（`@hello-pangea/dnd`，自带键盘拖拽与读屏支持，触屏可滚）。
`items`（每项须有唯一 `id`）/ `onReorder(next)` / `renderItem(item, index, isDragging)` / `direction`。

## 图表与日历

### `ChartContainer` / `ChartTooltip(Content)` / `ChartLegend(Content)` / `ChartStyle` ⭐
recharts 封装，形态沿用 shadcn/ui 官方 chart 组件（MIT），样式改走本库令牌。

**核心机制**：把 `config` 里每个系列的色值，按主题注入成 CSS 变量 `--color-<key>`，图上各处写 `var(--color-xxx)`。于是**双主题图表不需要在 JS 里读当前主题**：

```tsx
const config = {
  tokens: { label: '消耗', theme: { light: 'var(--chart-2)', dark: 'var(--chart-2)' } },
} satisfies ChartConfig

<ChartContainer config={config} className="aspect-auto h-52 w-full">
  <AreaChart data={data}>
    <CartesianGrid vertical={false} />
    <XAxis dataKey="day" tickLine={false} axisLine={false} />
    <ChartTooltip content={<ChartTooltipContent />} />
    <Area dataKey="tokens" stroke="var(--color-tokens)" fill="var(--color-tokens)" fillOpacity={0.25} />
  </AreaChart>
</ChartContainer>
```

`ChartContainer` 内置了把 recharts 各处硬编码中性色（axis 文字、网格线、光标、圆点描边）统一换成令牌色的样式规则，所以图表不用逐个配颜色就跟主题一致。`initialDimension` 是容器测量出真实尺寸前的兜底尺寸，防首帧高度塌成 0。

⚠ 单独用 `recharts` 原生组件时是**不会**继承令牌色的，必须走 `ChartContainer`。

### `Calendar` / `CalendarDayButton`
react-day-picker 封装（形态同样沿用 shadcn/ui，MIT）。单选 / 区间都可：
```tsx
<Calendar mode="single" selected={date} onSelect={setDate} />
<Calendar mode="range"  selected={range} onSelect={setRange} numberOfMonths={2} />
```
放进 Popover 时给它 `autoFocus`，否则键盘用户点开日历要再 Tab 一次才进得去。
`buttonVariant` 可换翻页按钮的按钮样式；`--cell-size` 由 `--spacing(8)` 派生，改令牌即整体缩放。

## 通用件

| 组件 | 要点 |
|---|---|
| `AnimatedNumber` ⭐ | `value` 变化时从旧值补间到新值（motion `animate()`）。只做数字补间，格式化交给调用方或 `formatCount`。 |
| `CopyButton` ⭐ | 两个图标叠在**同一格**（`grid` 同行同列）靠 `scale` + 延迟交叉淡换；图标尺寸不同也不会让按钮宽度跳动。`showToast={false}` 可只留图标反馈。 |
| `IconButton` ⭐ | 纯图标按钮（默认 `text-muted-foreground`，hover 变亮），给了 `tip` 自动套 Tooltip；`asChild` 可承载 motion 元素。删除类按钮传 `className="hover:text-destructive"` 覆盖。 |

**为什么不直接用 `<Button variant="ghost">` 做图标按钮**：ghost 自带背景与内边距，要用它得写三个类抵消；
且 `Button` 基类里的 `transition-all` 会和承载的 motion 子元素抢 `transform`。图标按钮该是另一条路。

### `MorphingDialog` ⭐
触发器与弹窗**共用同一个 `layoutId`**，motion 插值位置与尺寸：列表卡片点开后"就地放大"成弹窗，关掉缩回原位。

```tsx
<MorphingDialog transition={{ type: 'spring', bounce: 0.2, duration: 0.4 }}>
  <MorphingDialogTrigger><Card>点我</Card></MorphingDialogTrigger>
  <MorphingDialogContainer>
    <MorphingDialogContent dismissOnClickOutside ignoreOutsideClick={…}>
      <MorphingDialogTitle>标题</MorphingDialogTitle>
      <MorphingDialogDescription>说明</MorphingDialogDescription>
      <MorphingDialogClose />
    </MorphingDialogContent>
  </MorphingDialogContainer>
</MorphingDialog>
```

两个关键实现细节（**别省**）：
1. 打开时触发器换成**等尺寸的普通占位元素**（`visibility:hidden`）而不是 motion 元素。
   否则 motion 在内部重排时会把触发器"闪回"原位，视觉上抽动一下。
2. 关闭时用 `AnimatePresence` 包住容器，让缩回动画播完再卸载。

已内置：Esc 关闭、焦点锁在弹窗内、打开锁 body 滚动、关闭把焦点还给触发器、
点外部关闭（默认放行 select/popover/tooltip 的 portal 层，否则一点下拉就把弹窗关了）。

## Hook 与模式

### `useEventSource` ⭐
通用 SSE 流：**支持自定义请求头**（`EventSource` 原生不支持，所以用 `fetch` + `ReadableStream` 自己解帧）、
可中止、断线指数退避重连、可选把 `data` 当 JSON 解析。

```ts
const { status, events, error, close } = useEventSource<LogLine>('/api/v1/log/stream', {
  headers: { Authorization: `Bearer ${key}` },
  parseJson: true,
  reconnect: { attempts: 5, baseDelay: 1000 },
  onMessage: (event) => …,
})
```

### `useClickOutside`
`useClickOutside(ref, handler, shouldIgnore?)`。第三个参数是"算外部但不触发"的判定，
默认实现会放行所有浮层 portal —— 这是弹窗里能用下拉的必备条件。

### `usePageActions` ⭐（页面动作上浮模式）
顶栏属于布局层、按钮属于业务页。正常写法要把动作一路 props 传上去（prop 钻井）；
改成页面挂载时把动作注册到全局 store、卸载时清掉，外壳只读 store。

```tsx
usePageActions('channel', [
  { id: 'create', label: '新建', icon: Plus, onSelect: () => setOpen(true) },
  { id: 'del', label: '删除', destructive: true, onSelect: removeSelected },
])
```

⚠ 卸载清理必须判 `owner` 归属，否则快速切页时旧页面的 unmount 会把新页面的动作一起清掉
（旧页面 unmount 发生在新页面 mount 之后，是真实会踩到的顺序）。
