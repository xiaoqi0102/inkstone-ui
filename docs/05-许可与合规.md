## 2. 设计参考来源（诚实说明）

本库的**设计语言与部分交互规则**是研究开源项目
[`bestruirui/octopus`](https://github.com/bestruirui/octopus)（**AGPL-3.0**）的前端之后**重新实现**的：

- 组件代码为**独立编写**，与本仓库无关的源码不作逐行对应；
- 视觉层做了替换：**令牌色值整套重写**（自有暖纸 + 钢蓝体系，见 `06-设计方案.md` §2），
  中性色色温、危险色映射、图表配色均与任何既有项目无关；
- 提炼的是「做法」（如标题只截断自己、请求还原三规矩、虚拟滚动三坑），并**写成本库自己的规范**（`07-设计规范.md`）。

之所以要说明这一点：AGPL-3.0 是强传染性许可，我们**不希望**把本库的使用者拖进它的义务里，
因此没有复制其源码、色值与视觉形态。若上游作者对此有异议，欢迎开 issue 沟通。

> 本仓库**不包含**任何来源项目的业务模块、内部数据或私有配置。

## 4. 换色 / 换形态（二次开发提示）

如果你想把这套 UI 用在自己的产品上（甚至改成自己的品牌），**不需要**动组件代码，只改令牌：

1. 换 `--primary` / `--accent` / `--ring`（浅深各一套，共 6 处）；
2. **守住色温铁律**（中性色暖带 55°~95°、品牌色冷带）——见 `06-设计方案.md` §2.3；
3. 复核对比度（别靠肉眼，见 `07-设计规范.md` §1.1.2）；
4. 若要换导航形态：`DockNav` 的胶囊可以换成普通侧栏，形态是本库最"显眼"的部分。

> 一句话：**令牌是可换的，规则是可学的。**
