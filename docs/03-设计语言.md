# 03 · 设计语言（令牌与规则速查）

> 本文件是**速查版**：讲清「令牌叫什么、什么调性、什么时候不能用」。
> 要**完整规范**（组件 Props / 状态矩阵 / 模式 / 自查清单）请看 [`07-设计规范.md`](07-设计规范.md)；
> 两者与源码冲突时，**一律以源码为准**。

## 1. 颜色：oklch 色板

全站颜色用 **oklch**（感知均匀），写在 `src/styles/tokens.css`，浅色在 `:root`、深色在 `html.dark, .dark`。换肤只需改 `<html>` 的 class。

**调性一句话**：暖象牙纸面 + 深棕墨字 + 一处钢蓝。深浅两套都**取暖**，品牌蓝是唯一的冷点。

> **色温铁律（改色前必读）**：所有中性色（底 / 卡 / 静默 / 描边 / 次级 / 抬升）色相统一落在**暖带 55°~95°**；
> 品牌蓝与图表冷色统一落在**冷带 248°~258°**。
> 违反后果是具体的：把 `--muted` / `--border` 调成冷色后，卡片里的进度轨、分隔线、输入框描边会与暖卡底
> 「冷暖咬合」，整片发脏——这是本套色板第一次迭代时踩过的坑。

| 角色 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--background` | `oklch(0.9700 0.0150 92.0000)` | `oklch(0.2250 0.0060 65.0000)` | 页面底（暖象牙 / 暖炭） |
| `--foreground` | `oklch(0.3393 0.0153 59.1000)` | `oklch(0.9350 0.0100 92.0000)` | 正文 |
| `--card` | `oklch(0.9930 0.0045 95.0000)` | `oklch(0.2750 0.0065 65.0000)` | 卡片底（比页面底更干净：读作「纸上纸」） |
| `--popover` | `oklch(0.9930 0.0045 95.0000)` | `oklch(0.2750 0.0065 65.0000)` | 浮层底（tooltip / 下拉 / popover / 弹窗） |
| `--raised` | `oklch(0.9930 0.0045 95.0000)` | `oklch(0.3700 0.0080 65.0000)` | 抬升面：要从底座上浮起来的选中项 / 开关滑块 / 浮层内可选面 |

| `--destructive-foreground` | `oklch(0.9900 0.0080 95.0000)` | `oklch(0.2050 0.0120 65.0000)` | 危险实底之上的文字 |

| `--input` | `oklch(0.8900 0.0100 85.0000)` | `oklch(0.3750 0.0090 65.0000)` | 表单控件描边（与 `--border` 同值，语义分开） |
| `--ring` | `oklch(0.5000 0.0850 248.0000)` | `oklch(0.7300 0.0850 248.0000)` | 焦点环（与 `--primary` 同值，改色一起改） |

**主按钮为什么要 `--accent`**：`Button variant="gradient"` 是 `from-primary to-accent` 的渐变 + 近白文字。
所以 `--accent` **必须与 `--primary` 同样深**——它一旦被调亮，渐变末端的文字对比度立刻掉到 AA 以下（早期版本就是这个问题，实测 2.60:1）。

**深色下的危险色**：暗底上若还把深红当文字色用，实测只有 2.4:1，看不清。所以深色按「与 `--primary` 同构」的规则映射：
取**浅红做面色/文字色 + 深棕做字**（`oklch(0.8400 0.1200 30.0000)` / `oklch(0.2050 0.0120 65.0000)`），与浅色（`oklch(0.5500 0.1500 30.0000)` / `oklch(0.9900 0.0080 95.0000)`）**不同值**。

**图表五色**：三档钢蓝同色相递降亮度（主序列）+ 两支暖褐（对比序列）。浅色 `--chart-1..5` =
`oklch(0.6800 0.0900 248.0000)` / `oklch(0.5700 0.1000 252.0000)` / `oklch(0.4600 0.0900 256.0000)` / `oklch(0.6800 0.0620 62.0000)` / `oklch(0.5200 0.0420 75.0000)`。

**侧栏 / Dock 一套独立令牌**（导航用，值得与主区不同深浅）：`--sidebar`（深棕墨轨道）、`--sidebar-foreground`、
`--sidebar-primary`（激活滑块底）、`--sidebar-primary-foreground`、`--sidebar-accent`（悬浮滑块底）、
`--sidebar-accent-foreground`、`--sidebar-border`、`--sidebar-ring`。导航区**禁止**写 `bg-primary` / `text-foreground`。

**没有 `--success` / `--warning` 令牌**（别去找）：`Badge` 的 `success` / `warning` 变体用的是 Tailwind 字面色
`emerald` / `amber`（`bg-emerald-500/15 text-emerald-700 dark:text-emerald-400`），不进令牌体系。
浅色取 `700` 档（`600` 在暖象牙底上只有 3.1:1，不达 AA）。若要把它们纳入主题化，需要自己往 `tokens.css` 加一对并改 `badge.tsx`。

Tailwind v4 里通过 `@theme inline` 把变量映射成工具类：

```css
@theme inline {
  --color-background: var(--background);
  --color-primary: var(--primary);
  --color-sidebar: var(--sidebar);
  /* → 于是有 bg-background / text-primary / bg-sidebar 等类 */
}
```

新增令牌必须**同时**加三处：`:root`、深色块、`@theme inline`，漏一处就不生效。

## 2. 柔光背景

```css
body::before, body::after {
  content: ''; position: fixed; border-radius: 50%; pointer-events: none;
  filter: blur(100px); opacity: .15;  /* 暗色 .1 */
}
body::before {  /* 品牌蓝，左上 */
  width: 60vw; height: 60vw; background: oklch(0.68 0.05 232);
  top: -20vw; left: -20vw;
}
body::after {   /* 浅一档，右下 */
  width: 50vw; height: 50vw; background: oklch(0.78 0.03 240);
  bottom: -15vw; right: -15vw;
}
```

两层大半径模糊光斑，给纯色底加「环境光」。成本极低，但一眼就有氛围。
这两个色值是**字面量**（刻意不进令牌：它们是环境光，不参与语义），换主色时要一起看。
注意 `pointer-events: none` 必须给，否则会吃掉点击。

## 3. 形状与阴影

- 圆角基值 `--radius: 0.5rem`；由它派生 `sm/md/lg/xl/2xl`（`calc` 递减）。再往外更圆的（导航 `rounded-3xl`、按钮 `rounded-2xl`）直接用 Tailwind 档位。
- 阴影是**自定义 8 档** `--shadow-2xs…2xl`（`0 1px 3px 0 hsl(0 0% 0% / …)` 逐级加深），另有一套 `--shadow-inset-*` 内阴影用于「凹陷」控件。不要用 Tailwind 默认 `shadow-md`——深浅主题下对比度不匹配。
- `Card` 支持 `glow`：用 `::before` 铺一层从左上角散开的 `color-mix(in oklab, var(--primary) 8%, transparent)`。

## 4. 字体与排版

- 正文没引外部字体，走系统栈；**数字一律加 `tabular-nums`**（统计卡、表格、耗时），否则数字变化时宽度跳动。
- 字重阶梯：页面名 `text-3xl font-bold`；Card 标题 `font-semibold`；正文 `text-sm`；说明/次要 `text-xs text-muted-foreground`。
- 标题过长**只截断自己**（`min-w-0 truncate`），旁边按钮 `shrink-0` —— 见 `PageHeader`。

## 5. 图标规范

- 来源 `lucide-react`，**一律禁掉默认 24px**，按阶梯显式给尺寸：
  - 行内/按钮内 `size-4`（16px）
  - 导航项 `size-5`~`size-6`
  - 卡片标题图标 `size-4`
  - 纯图标按钮外框 `size-8`/`size-9`，内含 `size-4`
- 统一 `strokeWidth={2}`；不要混用 1.5/2.5。

## 6. 动效规范

| 场景 | 时长 | 缓动 |
|---|---|---|
| 悬浮/颜色/图标交叉 | 150–200ms | `ease-out` / `linear` |
| 滑块、指示器位移 | 300ms | `ease-out` |
| 弹窗进出（含形变） | 300–400ms | `spring { bounce: 0.2, duration: 0.4 }` |
| 数字滚动 | 800ms | `easeOut` |

三条铁律：
1. **尊重 `prefers-reduced-motion`** —— 关键过渡加 `motion-reduce:transition-none`（`CopyButton` 已示范）。
2. **微交互别过度**：悬浮只做「颜色 + 轻微 scale（≤1.1）」，不要位移超过 4px。
3. **动画只用于表达状态变化**（页面切换方向、值更新、开合），不做无意义的循环动画。

## 7. 滚动条

```css
* { scrollbar-width: none; }          /* Firefox */
*::-webkit-scrollbar { display: none; } /* WebKit */
```

全站隐藏滚动条（内容仍可滚）。这决定了**内容区必须有其它「还有更多」的暗示**（底部渐隐、总条数 Badge）。

## 8. 必守的布局规则（踩坑清单）

1. 内容区用 `minmax(0,1fr)` / `min-h-0`，否则子元素撑破行高，滚不起来。
2. 标题与动作同行：标题 `min-w-0 truncate`，动作 `shrink-0 whitespace-nowrap`，**绝不换行**。
3. 同类区块（同一页里两组「标题 + 按钮」）用同一个 `PageHeader`，保证左右边缘对齐。
4. 长文本块（prompt / 响应）多行展示，不压行。
5. 虚拟滚动容器必须有确定高度。
6. 图表（recharts）不要绕开 `ChartContainer`；recharts 2/3 的类名写法不同，改选择器后要 `getComputedStyle` 实测渲染色（详见 07 §2.3）。
