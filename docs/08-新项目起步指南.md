# 08 · 新项目起步指南（从零到跑起来）

本指南里的每一条命令、每一段配置，都在一个真实的消费者工程（Vite + React 19 + TS）里跑通过
（`npm install` → `tsc --noEmit`（0 错）→ `vite build`（通过）→ 实机截图 4 页无报错）。
照抄即可，不需要猜。

---

## 0. 前置

| 项 | 版本 | 说明 |
|---|---|---|
| Node | ≥ 20 | Vite / Tailwind v4 都要求 |
| React | 19 | 本库按 React 19 写（`use` / 新 JSX 转换） |
| Tailwind | v4 | 主题在 CSS 里，不是 `tailwind.config.js` |
| 构建器 | Vite | 其他构建器可用，但 `optimizeDeps.exclude` 是 Vite 的写法 |

---

## 1. 建工程

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
npm install -D tailwindcss @tailwindcss/vite tw-animate-css
```

（`tw-animate-css` 提供本库用到的进入/退出动画工具类，如 `animate-in` / `fade-in`。）

---

## 2. 装组件库

```bash
cp /path/to/inkstone-ui-0.1.0.tgz .
npm install ./inkstone-ui-0.1.0.tgz
```

装完在 `package.json` 里会看到 `"inkstone-ui": "file:./inkstone-ui-0.1.0.tgz"`。
也可以放进私有 registry 后 `npm i inkstone-ui`，代码侧完全一样。

---

## 3. 接三处线（缺一不可）

### 3.1 `vite.config.ts`

```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
    plugins: [react(), tailwindcss()],
    optimizeDeps: { exclude: ['inkstone-ui'] },
})
```

### 3.2 `src/index.css`（入口样式）

```css
@import "tailwindcss";
@import "tw-animate-css";
@import "inkstone-ui/styles/tokens.css";
@import "inkstone-ui/styles/base.css";

/* 让 Tailwind 扫到库源码里用到的工具类 */
@source "../node_modules/inkstone-ui/src";
```

### 3.3 `src/main.tsx`（根节点）

```tsx
import { createRoot } from 'react-dom/client'
import { UIKitProvider } from 'inkstone-ui'
import './index.css'
import { App } from './App'

createRoot(document.getElementById('root')!).render(
    <UIKitProvider>
        <App />
    </UIKitProvider>,
)
```

## 4. 写第一个页面（可直接复制运行）

```tsx
import { useState } from 'react'
import { Activity, Home, ScrollText, ServerCog } from 'lucide-react'
import {
    AppShell, Badge, DockNav, PageHeader, Sparkline, StatCard,
    VirtualizedList, formatCount, type DockNavItem,
} from 'inkstone-ui'

const NAV: DockNavItem[] = [
    { id: 'home', label: '概览', icon: Home },
    { id: 'channels', label: '渠道', icon: ServerCog },
    { id: 'logs', label: '日志', icon: ScrollText },
]
const TITLES = { home: '运行概览', channels: '渠道管理', logs: '请求日志' } as const

const LOGS = Array.from({ length: 500 }, (_, i) => ({ id: `req-${i}`, model: 'gpt-5.1', ok: i % 7 !== 0, ms: 420 + (i % 900) }))
const TREND = [12, 18, 14, 24, 20, 27, 22].map((v, i) => ({ d: `-${6 - i}d`, v }))

export function App() {
    const [page, setPage] = useState<'home' | 'channels' | 'logs'>('home')
    const cnt = formatCount(9_812_345)

    return (
        <AppShell
            nav={<DockNav items={NAV} value={page} onChange={(id) => setPage(id as typeof page)} />}
            title={TITLES[page]}
            actions={<Badge variant="success">在线</Badge>}
        >
            {page === 'home' && (
                <div className="grid gap-3 md:grid-cols-2">
                    <StatCard label="今日请求" value={cnt.formatted.value} unit={cnt.formatted.unit}
                        icon={Activity} trend={12.4} footer={<Sparkline data={TREND} dataKey="v" />} />
                    <StatCard label="平均耗时" value={742} unit="ms" icon={Activity} trend={-2.1}
                        footer={<Sparkline data={TREND} dataKey="v" color="var(--chart-3)" />} />
                </div>
            )}

            {page === 'logs' && (
                <div className="flex h-full min-h-0 flex-col gap-3">
                    <PageHeader title="请求日志" description={`${LOGS.length} 条`} />
                    <div className="min-h-0 flex-1 rounded-xl border border-border bg-card">
                        <VirtualizedList
                            items={LOGS} estimateSize={46} gap={2} className="p-2"
                            getItemKey={(l) => l.id}
                            renderItem={(l) => (
                                <div className="flex items-center gap-3 rounded-lg px-3 py-2 text-xs hover:bg-secondary/50">
                                    <Badge variant={l.ok ? 'success' : 'destructive'}>{l.ok ? '200' : '500'}</Badge>
                                    <span className="font-mono">{l.model}</span>
                                    <span className="ml-auto tabular-nums text-muted-foreground">{l.ms}ms</span>
                                </div>
                            )}
                        />
                    </div>
                </div>
            )}

            {page === 'channels' && (
                <div className="flex flex-col gap-3">
                    <PageHeader title="渠道管理" description="换页只换 title + children，外壳只渲染一次" />
                    <div className="rounded-xl border border-border bg-card p-5 text-sm text-muted-foreground">
                        这里放你的内容。注意外壳内的内容区自己有滚动，页面根节点建议
                        <code className="mx-1 rounded bg-secondary px-1">h-full min-h-0 flex-1 flex-col</code>
                        起手。
                    </div>
                </div>
            )}
        </AppShell>
    )
}
```

### 4.1 页面骨架的三段式

```
UIKitProvider
└─ AppShell（nav + logo + title + actions）← 一屏只有一个
   └─ main（flex-1 min-h-0 flex flex-col）
      ├─ PageHeader（左标题/描述 + 右动作，同一页多组必须都用它）
      └─ 内容区（flex-1 min-h-0；长列表交给 VirtualizedList）
```

**为什么页面里要带 `h-full min-h-0 flex-1 flex-col`**：`AppShell` 的内容区是 flex 容器，父链上任何一环缺 `min-h-0`，子元素的 `flex-1` 就撑不出可滚动高度 —— 症状是"列表不滚、整页一起滚"，且不报错。

## 5. 跑起来并验证

```bash
npm run dev            # 开发（本指南验证时用的是 vite build + 静态预览）
npx tsc --noEmit       # 必须 0 错误
npx vite build         # 必须通过
```

**验证清单（都过了才算接好）**：

| # | 检查 | 期望 |
|---|---|---|
| 1 | `npm ls react` | 只有一个 react 版本 |
| 2 | 页面背景 | 是令牌色（浅色暖米 / 深色墨绿），不是纯白/纯黑 |
| 3 | 深色切换 | 点右上角图标能切，且**刷新后保持**（`localStorage.theme`） |
| 4 | 长列表 | 滚得动、只渲染视口内的行（DevTools Elements 里 DOM 节点数远少于数据条数） |
| 5 | 任意卡片 | 有圆角、有柔光、有边框（说明 `@source` 生效了） |
| 6 | 控制台 | 无 warning、无 pageerror |

## 6. 五个必踩的坑（症状 → 原因 → 解法）

| 症状 | 原因 | 解法 |
|---|---|---|
| 白屏，控制台只有 `Tooltip must be used within TooltipProvider` | 根节点漏了 `UIKitProvider` | 按 3.3 包上 |
| 构建报 JSX 解析错误 | 漏了 `optimizeDeps.exclude` | 按 3.1 加上 |
| 能构建、不报错，但**页面全是裸样式** | 漏了 CSS 里的 `@source`，库里的工具类没被生成 | 按 3.2 加上 |
| `Invalid hook call` / 状态错乱 | 装了两份 React（库的依赖和你的版本没去重） | 删掉库的 `node_modules/react`，确认 `peerDependencies` 生效 |
| 引了 `@radix-ui/react-xxx` 报类型不兼容 | 混装了两套 radix（聚合包 + 单包） | 只保留 `radix-ui` 聚合包 |
